1. Introduction

La présente Politique de Confidentialité décrit comment Cantiques Célestes collecte, utilise, protège et partage vos données personnelles lorsque vous utilisez l'application mobile Cantiques Célestes.

Cette politique respecte les exigences de Google Play et des règlements sur la protection des données (RGPD, CCPA).

2. Données collectées

2.1. Données d'authentification (Google Sign-In)

Lorsque vous vous connectez via Google Sign-In, nous recevons :

  • Adresse email Google
  • Nom d'affichage Google
  • Photo de profil Google (optionnelle)

Fournisseur : Google Firebase Authentication
Stockage : Les données d'authentification sont gérées par Firebase et ne sont pas stockées sur nos serveurs.

2.2. Données de conversation (MCIA Chat)

Lorsque vous utilisez l'assistant IA MCIA :

  • Messages envoyés (vos questions et demandes)
  • Historique de conversation (stocké localement sur votre appareil)
  • Réponses générées par l'IA

Stockage serveur (optionnel) : Si la persistance conversationnelle est activée, l'historique peut être stocké sur nos serveurs SQLite. Vous pouvez désactiver cette fonctionnalité à tout moment.

2.3. Données de génération musicale

Lorsque vous générez de la musique :

  • Thème/message de la demande (ex: "chanson sur la grâce")
  • Paroles générées par l'IA
  • Fichiers audio générés (stockés localement sur votre appareil)

2.4. Données techniques

  • Adresse IP (pour le rate limiting — 10 requêtes/60 secondes)
  • Type d'appareil (User-Agent HTTP)
  • Logs d'erreur serveur (anonymisés — pas de lien avec votre identité)

2.5. Données NON collectées

Nous ne collectons PAS :

  • ❌ Votre position géographique (GPS)
  • ❌ Vos contacts
  • ❌ Votre historique de navigation
  • ❌ Vos données bancaires
  • ❌ Votre identité exacte (au-delà du nom Google)
  • ❌ Vos mots de passe (l'authentification est déléguée à Google)

3. Utilisation des données

3.1. Finalités

Vos données sont utilisées pour :

  • Authentifier votre session (Google Sign-In)
  • Fournir le service MCIA (traiter vos messages et générer des réponses)
  • Générer de la musique (paroles + audio via ACE-Step)
  • Prévenir les abus (rate limiting par IP)
  • Améliorer le service (logs d'erreur anonymisés)
  • Diagnostiquer les problèmes techniques

3.2. Base légale (RGPD)

  • Consentement : Vous consentez à l'utilisation de vos données en installant et utilisant l'application
  • Exécution d'un contrat : Vos données sont nécessaires pour fournir le service demandé
  • Intérêt légitime : Rate limiting et sécurité du service

6. Sécurité des données

6.1. Mesures techniques

  • HTTPS/TLS : Toutes les communications sont chiffrées
  • Authentification Firebase : Aucun mot de passe stocké côté serveur
  • Rate limiting : 10 requêtes/60 secondes par IP (protection anti-abus)
  • Validation anti-injection : Les messages sont validés (anti-XSS, anti-injection system prompt)
  • Clés API sécurisées : Les clés API ne sont jamais exposées au client

6.2. Limites

Malgré ces mesures, aucune transmission Internet n'est 100% sécurisée. Nous ne pouvons garantir une sécurité absolue.

7.1. Droits applicables

  • Droit de rectification : Corriger des données inexactes
  • Droit d'effacement : Demander la suppression de vos données

  • Droit de portabilité : Recevoir vos données dans un format structuré

Pour supprimer immédiatement votre historique local :

  • Android : Paramètres → Applications → Cantiques Célestes → Effacer les données
  • Ou désinstallez l'application

8. Confidentialité des enfants

L'application Cantiques Célestes ne s'adresse pas spécifiquement aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles d'enfants. Si vous pensez qu'un enfant nous a fourni des données, contactez-nous pour les supprimer.

9. Cookies et traceurs

L'application mobile Cantiques Célestes n'utilise PAS de cookies publicitaires ni de traceurs tiers à des fins de marketing.

Les seuls éléments stockés localement sont :

  • Token d'authentification Firebase (pour maintenir la session)
  • Historique de chat MCIA (pour le contexte conversationnel)
  • Fichiers audio téléchargés (musique générée)
  • Préférences utilisateur (langue, thème)

10. Transferts hors UE

Vos données peuvent être traitées par des serveurs situés hors de l'Union Européenne :

  • Google Firebase (États-Unis) — protégé par les Clauses Contractuelles Type de la Commission Européenne
  • NVIDIA NIM (États-Unis)
  • PythonAnywhere (Royaume-Uni / États-Unis)

Ces transferts sont réalisés conformément au RGPD et aux décisions d'adéquation applicables.
